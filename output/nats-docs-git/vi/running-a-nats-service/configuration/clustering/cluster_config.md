# Cấu hình Clustering

> 🇬🇧 *The [`cluster` configuration map](..#clustering) has the following configuration options:*

[Config map `cluster`](..#clustering) (cấu hình) hỗ trợ các tùy chọn sau:

| Property                           | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Version |
|------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------|
| `host`                             | Interface mà gateway sẽ lắng nghe các kết nối route đến.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |         |
| `port`                             | Port mà gateway sẽ lắng nghe các kết nối route đến.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |         |
| `name`                             | Tên của cluster (khuyến nghị dùng với NATS +v2.2)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |         |
| `listen`                           | Kết hợp `host` và `port` thành `<host>:<port>`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |         |
| `tls`                              | [Config map `tls`](../securing_nats/tls.md) để bảo mật kết nối clustering. `verify` luôn được bật và `cert_file` dùng cho cả client lẫn server. [Xem thêm](../securing_nats/tls.md#wrong-key-usage) để tránh các lỗi phổ biến liên quan đến certificate.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |         |
| `advertise` or `cluster_advertise` | Hostport `<host>:<port>` để quảng bá cách các thành viên khác trong cluster có thể kết nối đến server này. Hữu ích trong các môi trường có NAT. Khi dùng TLS (mã hóa TLS), tham số này quan trọng vì nó kiểm soát hostname mà client sẽ dùng khi khám phá route — mặc định sẽ là địa chỉ IP, và nếu không đặt đúng, TLS hostname verification có thể thất bại với lỗi IP SANs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |         |
| `no_advertise`                     | Khi đặt là `true`, server sẽ không gossip URL của mình đến các client. Tùy chọn này cũng vô hiệu hóa `client_advertise` trong [mục cấu hình chung](..). Tắt hoàn toàn advertise có thể hữu ích khi server có thể được truy cập qua nhiều load balancer và interface từ các mạng khác nhau. Việc tự động quảng bá địa chỉ IP nội bộ có thể gây ra độ trễ khi reconnect do các lần thử kết nối thất bại.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |         |
| `routes`                           | Danh sách các server khác (URL) để tạo thành cluster. Các self-route sẽ bị bỏ qua. Nếu cần xác thực qua `token` hoặc `username`/`password`, hãy thêm chúng vào URL.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |         |
| `connect_retries`                  | Số lần thử kết nối thất bại trước khi từ bỏ việc thiết lập kết nối đến một discovered route. Mặc định là `0`, tức không retry (thử lại khi fail). Khi bật, sẽ thử lại mỗi giây. Không áp dụng cho các route được cấu hình tường minh.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |         |
| `connect_backoff`                  | Bật exponential backoff (chiến lược chờ tăng dần giữa các lần retry) khi reconnect. Nếu là `true`, sẽ bắt đầu từ 1 giây và tăng dần lên tối đa 30 giây.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | 2.12.0  |
| `authorization`                    | Map [Authorization](../securing_nats/auth_intro#authorization-map) để cấu hình các cluster route. Khi dùng một `username`/`password` duy nhất, nó xác định cơ chế xác thực mà server này kỳ vọng, cũng như cách server tự xác thực khi kết nối đến một _discovered_ route. Tùy chọn này không áp dụng cho các route được liệt kê tường minh trong `routes` — những route đó phải cung cấp credential trong URL. Với chế độ xác thực này, hãy dùng cùng credential trong toàn hệ thống hoặc liệt kê từng route tường minh trên mọi server. Nếu config map `tls` chỉ định `verify_and_map`, chỉ cần cung cấp `username` kỳ vọng. Các certificate khác nhau có thể được dùng nhưng phải map về cùng một `username`. Authorization map cũng cho phép `timeout`, tuy nhiên `users` và cấu hình `token` không được hỗ trợ và sẽ ngăn server khởi động. Block `permissions` sẽ bị bỏ qua. |         |
| `pool_size`                        | Kích thước connection pool dùng để phân phối tải cho các account không được pinned. Mặc định là `3`. Xem [v2 Routes](./v2_routes.md#connection-pooling) để biết thêm chi tiết.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |         |
| `accounts`                         | Danh sách tùy chọn các account sẽ có kết nối route được pinned. Xem [v2 Routes](./v2_routes.md#account-pinning) để biết thêm chi tiết.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |         |
| `compression`                      | Chế độ nén mà server sẽ dùng khi kết nối với các peer server. Mặc định là `accept`. Xem [v2 Routes](./v2_routes.md#compression) để biết thêm chi tiết.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |         |

```
cluster {
  name: example

  # host/port for inbound route connections from other server
  listen: localhost:4244

  # Authorization for route connections
  # Other server can connect if they supply the credentials listed here
  # This server will connect to discovered routes using this user
  authorization {
    user: route_user
    password: pwd
    timeout: 0.5
  }

  # This server establishes routes with these server.
  # This server solicits new routes and Routes are actively solicited and connected to from this server.
  # Other servers can connect to us if they supply the correct credentials
  # in their routes definitions from above.
  routes = [
    nats://route_user:pwd@127.0.0.1:4245
    nats://route_user:pwd@127.0.0.1:4246
  ]
}
```

## Thuật ngữ trong bài

- **backoff**: chiến lược chờ tăng dần giữa các lần retry
- **cluster**: cụm nhiều server chạy chung
- **config**: cấu hình
- **credential**: thông tin đăng nhập
- **permission**: quyền truy cập
- **retry**: thử lại khi fail
- **TLS**: mã hóa TLS
