# Đặt Tên Kết Nối

> 🇬🇧 *Connections can be assigned a name which will appear in some of the server monitoring data. This name is not required but can help in debugging and testing.*

Mỗi kết nối có thể được đặt tên — tên này sẽ hiển thị trong một số dữ liệu monitoring của server (máy chủ). Tên kết nối không bắt buộc nhưng hữu ích khi debug và test.
