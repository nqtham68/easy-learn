# Bắt Đầu

> 🇬🇧 *The best way to get the NATS Streaming Server is to use one of the pre-built release binaries which are available for OSX, Linux (x86-64/ARM), Windows.*

Cách đơn giản nhất để cài NATS Streaming Server là dùng các binary (file chương trình đã biên dịch) release dựng sẵn, có sẵn cho OSX, Linux (x86-64/ARM) và Windows.

> 🇬🇧 *Of course you can build the latest version of the server from the master branch. The master branch will always build and pass tests, but may not work correctly in your environment. First you will need at least Go version 1.11+ installed on your machine to build the NATS Streaming Server.*

Bạn cũng có thể tự build (biên dịch/đóng gói) phiên bản mới nhất của server (máy chủ) từ nhánh master. Nhánh master luôn build thành công và pass test, nhưng có thể không hoạt động đúng trong môi trường của bạn. Trước tiên, cần cài Go phiên bản 1.11 trở lên để build NATS Streaming Server.

## Thuật ngữ trong bài

- **binary**: file chương trình đã biên dịch
- **build**: biên dịch/đóng gói
- **server**: máy chủ
