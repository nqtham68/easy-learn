# Tài liệu tham khảo NATS

> 🇬🇧 *This section of the documentation contains the reference documentation for the NATS network protocols used between clients applications and server and between nats servers interconnected in a cluster.*

Phần này cung cấp tài liệu tham khảo cho các giao thức mạng của NATS — bao gồm giao thức giữa client và server, cũng như giữa các NATS server kết nối với nhau trong một cluster (cụm nhiều server chạy chung).

## Thuật ngữ trong bài

- **cluster**: cụm nhiều server chạy chung
- **client**: bên gọi (phía người dùng)
- **server**: máy chủ
